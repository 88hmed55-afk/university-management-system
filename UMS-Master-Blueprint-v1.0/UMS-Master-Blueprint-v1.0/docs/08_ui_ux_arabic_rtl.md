# 8. تصميم الواجهة وتجربة الاستخدام العربية RTL

## التوجه البصري
واجهة مؤسسية هادئة وعملية. لا تفرط في البطاقات والتدرجات والظلال. الأولوية لسهولة إنجاز العمل، وضوح الحالة، وتجنب الخطأ. العربية RTL هي الاتجاه الافتراضي والإنجليزية مدعومة.

## التخطيط العام
- شريط جانبي قابل للطي للتنقل حسب الصلاحيات.
- شريط علوي للسياق (الحرم/الفترة عند الحاجة)، البحث، الإشعارات، الملف الشخصي.
- مساحة محتوى بعنوان واضح ومسار تنقل.
- صفحات القوائم تستخدم جداول بحث وفرز وفلاتر وترقيم.
- صفحات التفاصيل تستخدم تبويبات بحسب صلاحيات المستخدم.
- النماذج الطويلة تقسم إلى مجموعات أو معالج خطوات.
- شاشة الاعتماد تعرض ملخص القرار والأثر قبل الإجراء.

## مكونات مشتركة
Button variants، DataTable، Search/Filter bar، FormField، StatusBadge، ConfirmDialog، Timeline، FileUploader، AuditPanel، PermissionNotice، EmptyState، LoadingState، ErrorState، PrintHeader.

## قواعد RTL
- خصائص CSS المنطقية بدلاً من left/right.
- لا تعكس كل الأيقونات؛ اعكس اتجاه التنقل حيث يلزم.
- الأكواد والأرقام الجامعية والبريد تعرض LTR داخل حاويات منعزلة.
- اختبر حقول الهاتف والأرقام المختلطة والنسخ واللصق.
- الترويسات والنماذج والجداول والطباعة يجب أن تكون RTL حقيقياً، لا مجرد محاذاة يمين.

## قواعد النماذج
- تسمية واضحة وتعليمات مختصرة وإلزامية ظاهرة.
- لا تفقد القيم بعد خطأ التحقق.
- القوائم المترابطة (كلية ← قسم ← برنامج) لا تعرض عناصر غير مسموح بها.
- تحقق الخادم هو المرجع، والتحقق الأمامي مساعد فقط.
- الأزرار تسمي الإجراء بدقة: «إرسال للمراجعة» لا «حفظ» عندما تتغير الحالة.

## تجربة كل دور
- مدير الحرم يرى تشغيل الحرم والمرافق ومهام الموظفين التشغيليين.
- العميد يرى الكلية وأقسامها وبرامجها وقراراتها الأكاديمية المصرح بها.
- رئيس القسم يرى الشعب والمدرسين والنتائج الأولية.
- القبول يرى الطلبات والمرفقات والنواقص.
- المالية ترى الفواتير والمدفوعات والمطابقة.
- الطالب يرى التسجيل والجدول والنتائج المعتمدة والطلبات وحسابه فقط.
- المدرس يرى الشعب المسندة إليه ومهامه الأكاديمية فقط.

## حالات الواجهة
كل شاشة يجب أن تعالج: التحميل، الفراغ، لا نتائج، خطأ الخادم، عدم الصلاحية، انتهاء الجلسة، فشل رفع ملف، تعارض، نجاح الحفظ، انقطاع الشبكة، تكرار الإرسال.

## الطباعة والتصدير
قوالب رسمية ثابتة للشهادة والإفادة وكشف الدرجات والإيصال؛ شعار ورقم وثيقة وتاريخ واعتماد حسب القالب. دعم خط عربي في PDF. لا يتجاوز التصدير نطاق صلاحية الصفحة، ويسجل تصدير البيانات الحساسة.
