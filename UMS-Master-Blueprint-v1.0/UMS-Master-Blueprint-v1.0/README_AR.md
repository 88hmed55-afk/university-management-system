# حزمة المخطط الرئيسي UMS — الإصدار 1.0

**نظام معلومات وإدارة جامعة أهلية واحدة متعددة الأحرم**

## ابدأ من هنا
1. اقرأ `MASTER_PLAN_AR.docx` للقراءة والمراجعة والطباعة، أو `MASTER_PLAN_AR.md` للنسخة النصية الكاملة.
2. راجع `docs/04_screen_catalog.md`؛ يحتوي على 99 شاشة موصوفة برمز ثابت.
3. راجع `docs/06_data_model_dictionary.md` قبل اعتماد ERD النهائي وإنشاء migrations.
4. راجع `docs/14_decisions_pending.md` لمعرفة ما تم اعتماده وما ينتظر قرارات الجامعة.
5. افتح الرسومات داخل `diagrams/` في محرر يدعم Mermaid.
6. استخدم قوائم `checklists/` في ورش المتطلبات وقبل كل إطلاق.

## محتويات الحزمة
- وثيقة رئيسية بصيغتي DOCX وMarkdown.
- 15 فصلاً تفصيلياً: الرؤية والحوكمة، النموذج المؤسسي والأكاديمي، الوحدات وسير العمل، جرد الشاشات، الصلاحيات، قاموس البيانات، المعمارية التقنية، الواجهة العربية RTL، الأمن، التقارير والتحليلات، الاختبارات، التشغيل والنشر، خارطة التنفيذ، القرارات المعلقة، ودليل المطور.
- كتالوج 99 شاشة مع الهدف والحقول والإجراءات والمستخدمين وقواعد العمل والتحقق.
- 4 رسومات Mermaid للنموذج التنظيمي، دورة الطالب، ERD المفاهيمي، ومعمارية التطبيق.
- قوائم تحقق للتأسيس والقبول والإطلاق.
- مراجع تقنية رسمية.

## قرارات التصميم الأساسية
- مؤسسة جامعية واحدة متعددة الأحرم، وليست منصة متعددة الجامعات.
- الإدارة المركزية تملك السياسات والاعتمادات، ومديرو الأحرم يديرون التشغيل المحلي ضمن تفويض.
- لكل كلية عميد، ولكل قسم رئيس، ولا تتبع الكليات أكاديمياً مدير الحرم.
- الفصل بين البعد الأكاديمي والبعد المكاني والبعد الإداري التشغيلي.
- Modular Monolith كبداية، مع حدود وحدات واضحة.
- العربية RTL مع دعم الإنجليزية.

## أول خطوة تنفيذ فعلية
في PowerShell نفّذ:

```powershell
php -v
where.exe php
composer --version
node -v
npm -v
mysql --version
```

ثم افحص إصدار الخادم:

```sql
SELECT VERSION();
```

لا تفترض توافق XAMPP قبل الفحص. خط الأساس المستهدف في الوثيقة Laravel 13 مع PHP 8.3+ وMySQL 8.4 LTS، ويجب إعادة التحقق من توافق كل الحزم قبل تثبيت المشروع. XAMPP للتطوير المحلي فقط؛ لا تستخدم بيانات حقيقية في بيئة التطوير.

## ما الذي لا تحتويه الحزمة؟
هذه الحزمة **مخطط هندسي تنفيذي ووثائق تأسيس** وليست تطبيق Laravel مكتملاً أو قاعدة بيانات منشأة أو واجهات برمجية جاهزة. تنفيذ الكود يبدأ بعد فحص البيئة وإغلاق قرارات الجامعة ذات الأثر المباشر على البيانات والعمليات. لم تُخترع سياسات أكاديمية أو مالية غير معتمدة.

## ملاحظة عن نسخة Word
نسخة Word معدّة للقراءة والطباعة. بعض الجداول العريضة في الملفات المصدرية عُرضت فيها كبنود وصفية لتكون أوضح في اتجاه الكتابة العربية؛ أما الجداول التفصيلية الأصلية فتبقى محفوظة في ملفات Markdown داخل `docs/`.
