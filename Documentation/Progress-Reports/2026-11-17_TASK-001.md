# تقرير تنفيذ مهمة — TASK-001

**المهمة:** حسم سلسلة الأدوات المحلية (Toolchain Resolution)  
**التاريخ:** 17 نوفمبر 2026  
**الحالة النهائية:** `COMPLETED` مع مخاطرة تشغيلية موثّقة R-006

---

## 1. قرار المالك المنفَّذ
- ترقية PHP إلى 8.3+ مع تثبيت Composer، والإبقاء على Laravel 13.
- استخدام MySQL 8.4 LTS إن أُتيح؛ وإلا MySQL 8.0.38 مع توثيق الفروق.
- MySQL 8.4 LTS غير متاح محلياً، لذا اختير 8.0.38 وفق التفويض.

## 2. الأعمال المنفذة
1. تنزيل PHP 8.3.36 من الموقع الرسمي والتحقق من SHA-256.
2. استخراجه إلى `%LOCALAPPDATA%\UMS-Toolchain\php-8.3.36` وضبط `extension_dir`.
3. تفعيل الإضافات المطلوبة: `bcmath, curl, dom, fileinfo, gd, intl, mbstring, openssl, pdo_mysql, SimpleXML, xml, xmlreader, xmlwriter, zip`.
4. تنزيل Composer 2.11.2 والتحقق من SHA-256، وإنشاء `composer.bat` و`php.bat`.
5. إضافة مجلد `bin` إلى PATH على مستوى المستخدم.
6. توثيق المسارات والقيود في `Documentation/Installation/LOCAL_SETUP.md`.
7. تحديث ADR-005 وسجل القرارات وسجل التعارضات والمتابع.
