## 1. ما نُفّذ

1. **`courses`:** تعريف مركزي للمقرر برمز فريد وقسم مالك ووصف؛ لا حذف — أرشفة. **لا يُخلط تعريف المقرر بالشعبة** (docs/02 سطر 50).
2. **`course_versions`:** نسخ توصيف مرقمة لكل مقرر مع مخرجات ومحتوى وسريان وقرار اعتماد. **النسخة المعتمدة غير قابلة لتعديل حقولها الجوهرية**.
3. **`study_plan_versions`:** نسخ خطط مرقمة لكل برنامج بتاريخ اعتماد/سريان وحالة ومرجع قرار. **النسخة المعتمدة لا تُعدل**؛ الإصدار الجديد لا ينقل الطلاب تلقائياً (docs/02 سطر 53).
4. **`study_plan_courses`:** مقررات الخطة بنوع/ساعات/مستوى اختيارية. **حقول الساعات والمستوى فارغة افتراضياً** حتى اعتماد الجامعة (P-007/P-011)؛ لا قيمة ساعات مُخترعة.
5. **`course_prerequisites`:** متطلبات/مكافئات بين مقررات مع شرط وقرار. **يُمنع المتطلب الذاتي والدورات** خادمياً.
6. **`student_plan_assignments`:** ربط الطالب بنسخة خطة **معتمدة فقط** بفترة سريان ومرجع قرار، مع منع ربطتين نشطتين متداخلتين؛ الإغلاق بتاريخ النهاية لا بالحذف.
7. **إجراءات مفوّضة ومُدقَّقة:** `DefineCourse` (القيادة الأكاديمية/رؤساء الأقسام)، `ApproveStudyPlanVersion` (القيادة الأكاديمية)، `AssignStudentPlan` (التسجيل/القيادة الأكاديمية). رفض غير المخول مُختبر.
8. **اختبارات ومصانع:** 8 اختبارات Feature + ستة مصانع.

> لا أرقام مقررات أو ساعات أو مستويات أو أسماء حقيقية/مُفترضة (P-001/P-007/P-011).
