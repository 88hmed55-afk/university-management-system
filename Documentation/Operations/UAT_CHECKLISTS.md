## 0. طبيعة هذه القوائم

- هذه **قوائم بشرية للتوقيع**، لا اختبارات آلية ولا قرار إطلاق. التنفيذ من موظفي الجامعة، والتوقيع يرفق باسم المُختبِر والتاريخ والنتيجة.
- السيناريوهات منقولة من الوثائق المعتمدة (`UMS-Master-Blueprint-v1.0`) عبر `App\Support\PilotUatCatalog`؛ لا سيناريوهات مُخترعة ولا عتبات أداء مُفترضة.
- لا يُوقع على بند إلا بعد اعتماد السياسات المرتبطة به؛ البنود المعلّقة لا تُختبر ببيانات افتراضية تُصبح قاعدة نظام.

## 3. شروط القبول (من `docs/11`)

- [ ] كل متطلب له ID ومالك وسيناريو واختبار قبول (محقق في القوائم أعلاه).
- [ ] لا تُعتبر الصفحة مكتملة وحدها؛ يُختبر قاعدة العمل والصلاحية والتدقيق معاً.
- [ ] كل نموذج له تحقق خادمي ورسائل عربية.
- [ ] العمليات الحرجة قابلة لإعادة المحاولة دون تكرار.
- [ ] كل تقرير له مصدر وتعريف وتطابق.
- [ ] لا عيوب Critical/High مفتوحة قبل الإنتاج.

## 4. بنود معلّقة تمنع توقيع UAT نهائي

| البند | الأثر على UAT |
|---|---|
| P-003 / P-004 / P-007 | لا سياسة دراسات أو تقويم أو سلم درجات معتمد؛ لا يُختبر حساب أكاديمي نهائي. |
| P-012 / P-013 | لا عملة أو رسوم أو قواعد رد معتمدة؛ لا يُختبر كشف حساب نهائي. |
| P-019 | لا سيناريو حمل معتمد؛ لا قياس أداء نهائي. |
| P-022 | قوالب الطباعة الرسمية غير معتمدة؛ اختبار الطباعة العربية يبقى مفتوحاً. |
| P-020 | لا RPO/RTO؛ لا بوابة استعادة مختبرة. |
