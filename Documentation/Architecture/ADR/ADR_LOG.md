# سجل قرارات المعمارية (ADR) — UMS
**الإصدار:** 1.0 — **التاريخ:** 17 نوفمبر 2026  
**القاعدة:** كل قرار مهم يُسجّل بالسياق والقرار والبدائل والأثر. القرار المعلّق لا يُنفّذ قبل اعتماده.

---

## ADR-001 — استخدام Modular Monolith
- **الحالة:** مقبول (من D-008 في المخطط).
- **السياق:** معاملات القبول/الدرجات/الرسوم تحتاج قاعدة مركزية متماسكة؛ فريق واحد؛ لا حاجة مستقلة مقاسة للفصل.
- **القرار:** monolith بوحدات صريحة الحدود، Actions/Services وعقود تكامل.
- **البدائل المرفوضة:** Microservices الآن (تعقيد تشغيلي بلا مبرر)، تطبيق بلا حدود (فوضى ملكية البيانات).
- **الأثر:** انضباط في حدود الوحدات؛ انتقال لاحق محكوم بقياس.

## ADR-002 — RBAC + نطاق بيانات + سياق عملية
- **الحالة:** مقبول (الوثيقة 5 و9).
- **القرار:** Middleware + Policies/Gates + Scope-aware queries؛ الدور وحده لا يمنح الوصول.
- **البديل المرفوض:** إخفاء الأزرار في الواجهة كضبط أمني.
- **الأثر:** اختبارات IDOR ورفض أفقي/رأسي إلزامية لكل وحدة؛ التصدير والطباعة داخل النطاق.

## ADR-003 — إصدارات الخطط والسياسات وعدم إعادة كتابة الماضي
- **الحالة:** مقبول.
- **القرار:** `effective_from/effective_to/مرجع قرار` على العلاقات المتغيرة؛ الطالب مرتبط بإصدار خطة؛ لا نقل تلقائي؛ لا تعديل صامت لنتائج/فواتير منشورة.
- **الأثر:** جداول أكثر، لكن تقارير تاريخية موثوقة وتدقيق قابل للإثبات.

## ADR-004 — عربي RTL أصلي مع نظام تصميم مشترك
- **الحالة:** مقبول مبدئياً — **يخضع لبوابة اعتماد التصميم**.
- **القرار:** CSS منطقية (logical properties)، عزل الأكواد/الأرقام LTR، خطوط محلية احتياطية بلا اتصال خارجي، نظام مكوّنات واحد يخدم تجارب دورية مختلفة.
- **الأثر:** تكلفة ضبط أعلى عند البداية؛ منع تكلفة إعادة RTL لاحقاً.

## ADR-005 — خط الأساس التقني (Laravel 13 / PHP 8.3+ / MySQL 8.4 LTS)
- **الحالة:** **مقبول ومُنفَّذ جزئياً** — قرار المالك 17 نوفمبر 2026.
- **السياق:** المستهدف موثق في المخطط، لكن البيئة المحلية كانت PHP 8.2.12 وMariaDB 10.4.32/MySQL 8.0.38 وComposer غير مثبّت.
- **القرار:** ترقية PHP محمولة إلى **8.3.36** وتثبيت **Composer 2.11.2** والإبقاء على **Laravel 13**. محرك البيانات: **MySQL 8.4 LTS** إن أُتيح، وإلا **MySQL 8.0.38** مع توثيق الفروق. بما أن 8.4 غير متاح محلياً، استُخدم 8.0.38.
- **البديل المرفوض:** الانتقال إلى Laravel 12 على PHP 8.2 (كان مقترحاً كبديل، لم يُعتمد).
- **الأثر:** Gate 0 جاهز من ناحية PHP/Composer. خدمة `MYSQL80` متوقفة وتحتاج صلاحية إدارة (R-006). تفاصيل المسارات والتحقق في `Documentation/Installation/LOCAL_SETUP.md`.

## ADR-006 — نماذج الواجهات المرجعية كبوابة تصميم
- **الحالة:** مقبول مبدئياً.
- **القرار:** إنتاج 15 بنداً من قسم «اعتماد التصميم» كملف HTML مستقل بصرياً قبل تعميم التصميم على الوحدات.
- **البديل المرفوض:** تعميم التصميم على 99 شاشة ثم تعديله (كسر الاتساق).
- **الأثر:** اعتماد مبكر يمنع انحراف المكوّنات؛ النماذج ثابتة بلا Backend عن قصد.
